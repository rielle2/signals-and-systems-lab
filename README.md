# SignalLab · 信号与系统交互学习平台

以奥本海姆《信号与系统》第二版的知识体系为参考，通过原创中文讲解、分步例题、动态波形实验和练习评估，帮助大学生理解与复习信号与系统。当前文档对应 **v0.4.0-beta**；无需登录、服务器或付费服务。

[进入学习网站](https://rielle2.github.io/signals-and-systems-lab/) · [反馈问题 / 数学纠错](https://github.com/rielle2/signals-and-systems-lab/issues/new?template=bug_report.yml) · [Beta 支持范围与限制](BETA.md)

## 从波形理解概念

在实验室中改变参数，比较原信号、变换信号、卷积重叠区域或频谱。播放、暂停、逐帧和滑块用于实际模型计算，波形与数值同步更新。

自定义信号采用安全表达式解析器，不执行用户代码。例如：

```text
sin(2*pi*t)
exp(-t)*u(t)
u(t)-u(t-2)
t*(u(t)-u(t-1))
delta[n]-delta[n-2]
```

连续时间与离散时间分别处理。连续Dirac冲激使用独立权重模型，不当作普通有限数值函数；不支持的运算会明确拒绝。自定义卷积、频谱与重建采用界面标明的有限窗口或数值近似，适用前提和极点零点模型边界见 [BETA.md](BETA.md)。

## 从错误找到下一步练习

有效客观作答后可查看标准模型与作答的数学差异、逐步变换和关联题。在“薄弱项诊断”中按18类规则回看常见问题、最近出现时间、巩固状态，并进入由易到难的训练。每类有3道新增原创练习，已包含在400道总题量中。

诊断只匹配题目可信元数据和明确支持的旧题/实验家族，提示的是**可能原因**，不宣称知道学生的思考过程。多种错误模型同时吻合时均保留可能性；无法归类的错题仍进入错题本。无效输入、人工自评、未确认照片和不可靠识别不产生客观错因记录。CT分段与DT整数序列分开比较，连续冲激与不支持模型不强行生成诊断曲线。

## 拍照识别与答案核对

先独立画出答案，再拍照、选择图片或输入关键点。照片仅在当前浏览器本地处理，不上传、不调用在线API、不持久保存照片、文件名或EXIF。可旋转、裁剪、缩放预览，并人工校正透视。

程序可提供轴线/原点候选，但**不识别手写刻度数字**。需要标定原点、横纵已知点及真实数值，对照原图核对重建的数字波形，必要时修正分段/整数样本，再确认提交。判分比较数学信号，不比较图片相似度；不确定识别不会自动扣分。

当前支持有限分段常数/线性连续信号和有限离散序列，不是万能手写识别器；连续冲激箭头、任意正弦/指数曲线、OCR及复杂多图不在支持范围。也可完全不用照片，直接编辑关键点作答。实际拍照效果取决于图像与标定质量，详见 [Beta 测试说明](BETA.md)。

## 学习进度与掌握判定

建议先读定义与例题，再去实验室预测波形变化，最后通过不同练习检验理解。知识点至少完成 **5道不同客观题**后评估；章节至少完成 **10道不同客观题并覆盖3个知识点**，未达到门槛时显示“样本不足”。

| 本轮客观正确率 | 状态 |
| --- | --- |
| 低于60% | 需要加强 |
| 60%至不足80% | 学习中 |
| 80%及以上 | 已掌握 |

同一轮每道题首次有效作答计分。普通重做会更新错题状态并保存记录，不反复增加权重；完成5道不同题的重新测评并交卷后，可更新知识点评估。复杂推导题的人工核对与快速自测不计入客观正确率。

错因记录区分“待巩固”“已重做，待完整重测”“已通过重测纠正”，不把单次重做正确当成掌握。同一知识点至少两道不同题出错后，安排最后相关错误后1天的延迟重测；提前重做不能替代到期后的完整5题测评。章节和知识点掌握仍由上面的有效客观证据计算。

进度、收藏、错题、信号库和数字波形历史保存在当前浏览器的localStorage，不自动跨设备同步。升级沿用原记录键；清理网站数据、隐私模式、换浏览器或网址来源可能影响保存。建议定期导出学习记录，并单独导出自定义信号库；照片不随备份导出。

学习JSON采用格式v3，内部学习数据仍为version 2；保留最近1000条去重诊断事件和100轮重测。导入上限5MiB，先校验、显示摘要，再由用户确认合并或覆盖；取消或失败保持原记录，章节掌握度重新计算。覆盖会替换当前学习记录，请先备份；主题与独立信号库保持当前设置。旧版学习JSON仍经校验后支持导入。

## 打开与离线使用

直接访问上方网站链接。项目使用原生HTML、CSS、JavaScript与本地KaTeX，无需npm构建、在线API或运行时CDN。

离线使用时，从仓库下载**完整ZIP**并解压，保留 `index.html`、`css/`、`js/`、`assets/` 和 `vendor/` 目录，再用浏览器打开 `index.html`。也可在目录运行：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。在线网址不保证断网后首次打开；完整本地目录可离线运行。手机和平板采用响应式布局；iPadOS“文件”快速预览可能不执行脚本，建议直接访问网站。桌面触摸视口模拟不能代替Android、微信或Safari真机验证。
