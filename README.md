# SignalLab 2.2.2 Beta · 信号与系统交互学习

以奥本海姆《信号与系统》第二版的知识体系为参考，用原创中文讲解、逐步例题、波形实验和练习评估帮助本科生理解与复习。学习不需要登录或付费；本项目并非教材全文或官方配套产品。

## 跨浏览器动画与诊断

主题设置箭头中展开“动画效果”，可选自动、完整圆形扩散、优化圆形扩散、轻量过渡、无动画。未知环境默认保留原680ms圆形；自动策略只根据本会话连续有效测量调整，不按 Android、浏览器名或屏幕宽度降级。优化模式仍保留圆形和日月海景，使用520ms。系统减少动态效果时立即切换；缺少必要API时安全降级。

“动画效果”底部的“动画诊断”可按需查看、复制站点与主题资源版本、浏览器能力、偏好、实际路径和最近切换数据。rAF/长任务仅反映主线程，不能代表 GPU 开销或真机帧率。技术信息不会自动上传，也不包含学习进度、答题或自定义信号。请检查内容后再提交公开反馈。

本版资源使用版本查询参数，便于正常刷新后取得匹配的 JS/CSS；不清除 localStorage、缓存或 Cookie。顶部建议色使用标准 theme-color，浏览器原生状态栏仍由浏览器控制。Windows Edge/Chrome 与移动仿真已检查；Android Chrome、微信和 Safari 的实际设备表现仍需真机反馈。

## 昼夜主题

顶部海天胶囊开关在浅色/深色间切换；旁边设置入口提供“跟随系统 / 始终浅色 / 始终深色”。首次默认跟随系统，手动选择后保存。支持的浏览器从开关中心播放圆形扩散；减少动态效果时直接切换，旧浏览器使用短暂颜色过渡。切换不重置输入、实验参数或答题进度。

## 这版可以学什么

- **7章、45个知识点**：信号基础、系统性质、LTI、傅里叶分析、采样、拉普拉斯变换与Z变换。
- **239道分步例题**：每个知识点5道，共225道；每章另有2道综合题，共14道。先读题独立尝试，再依次展开提示、推导和答案。
- **309道固定练习**：277道可客观判分，32道计算或推导题需要人工核对。支持按章节、知识点、难度与题型练习，收藏及错题重做。
- **31个参数化波形练习家族**：在信号变换、系统性质、卷积、傅里叶、采样实验中，先观察、预测并作答，再看解析和动画。同一家族可以换参数练习，不计作无限多道不同测评题。
- **六个预设实验室与五类自定义工作区**：比较时不变检验的两条路径，观察卷积重叠、谐波合成、混叠，以及极点零点；输入自己的CT/DT表达式并保存到信号库。
- 公式速查、搜索、章节结构、考试速记、复习标记及本地备份。

## 建议的学习路线

1. 在知识点页先读直觉和定义，自己写出核心公式及适用条件。
2. 对照5道例题逐步核对。需要看图时进入对应实验，先预测参数变化的结果。
3. 完成不同的客观题，再查看掌握状态；把不理解的步骤标为需要复习。
4. 错题重做正确后会移出错题本。准备更新掌握状态时，从知识点页开始“重新测评”，完成5道不同题并交卷。

## 掌握状态怎样计算

知识点至少完成**5道不同客观题**后才评估；章节至少完成**10道不同客观题，覆盖3个知识点**后才评估。未达到门槛时显示“样本不足”。达到门槛后：

| 客观正确率 | 状态 |
| --- | --- |
| 低于60% | 需要加强 |
| 60%至不足80% | 学习中 |
| 80%及以上 | 已掌握 |

同一轮中，每道题的首次有效作答计分。普通重做会保存练习记录、更新错题状态，但不会反复增加权重或改写本轮得分。重新测评在完成5道不同题并交卷后建立新轮次，保留测评历史摘要。计算、推导题的自评以及知识点页的快速自测不计入客观正确率。

旧版学习记录会迁移：已有作答次数与可用历史记录保留；原先手动标记的“已掌握”保留为复习信息，不直接当作新版客观掌握证据。详见 [Beta 测试说明](BETA.md)。

## 打开、主题与离线使用

直接访问上方网站链接。网站使用本地HTML、CSS、JavaScript及随目录附带的KaTeX，学习和计算不依赖在线API。

首次默认跟随系统深浅主题；顶部按钮可以切换深浅色，“项目说明”中的主题偏好可恢复跟随系统。选择会在当前浏览器保存。开启系统“减少动态效果”时省略主题过渡；不支持较新动画接口的浏览器使用轻量切换。

离线使用时，下载仓库的**完整ZIP**并解压，保留目录结构，用浏览器打开 `index.html`。在线网址不保证在断网后首次打开；完整本地文件夹可以离线运行。iPadOS“文件”的快速预览可能不执行脚本，应使用支持完整本地网页的浏览器或阅读工具，或访问静态站点网址。移动视口仿真不能替代iPad/Safari真机验证。
