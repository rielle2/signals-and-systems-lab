# SignalLab 3.1.0 Beta · 信号与系统交互学习

以奥本海姆《信号与系统》第二版的知识体系为参考，用原创中文讲解、逐步例题、波形实验和练习评估帮助本科生理解与复习。学习不需要登录或付费；本项目并非教材全文或官方配套产品。

[打开学习网站](https://rielle2.github.io/signals-and-systems-lab/) · [反馈问题 / 数学纠错](https://github.com/rielle2/signals-and-systems-lab/issues/new?template=bug_report.yml) · [Beta 测试说明](BETA.md)

## 图标与操作反馈

菜单、播放、展开和收藏使用轻量SVG变形反馈；普通工具与照片操作统一为线性图标。收藏保留当前照片和作答草稿，触摸控件扩大点击区域。原海天昼夜按钮和圆形扩散保持，减少动态效果时图标直接更新。Morphicons2.0.2以MIT许可证随站点本地分发，不依赖运行时CDN或React；无需安装即可访问/离线打开。真实手机兼容性与性能仍需实际设备验证，桌面模拟不能代替真机测试。

## 新增拍照与关键点绘图练习

侧栏“拍照绘图练习”新增19道原创题（13道CT、6道DT）：先独立绘制，再使用相机、相册、电脑选择或拖放PNG/JPG/WebP。照片在本机处理，不上传、不调用在线API，也不保存照片、文件名或EXIF。可旋转、裁剪、缩放预览并用四角校正透视。

程序可建议轴线与原点，但不识别手写刻度数字。请标原点、横纵已知点及真实数值，对照照片检查重建波形，必要时编辑分段／整数样本或拖动关键点，再确认提交。也可直接使用关键点作答。判分比较数学信号，不比较两张图片；不确定识别不会自动扣分。

首版限有限分段常数/线性CT信号和有限DT序列；连续冲激箭头、任意正弦/指数曲线、复杂多图或OCR不在支持范围。模糊、多曲线、黑笔与轴线重叠会要求重拍或实际人工修正并再次确认。有效判题关联原错题本、掌握评估和最多80条数字波形历史；照片不随备份导出。详情见 [Beta 测试说明](BETA.md)。

## 昼夜主题

顶部海天胶囊开关在浅色/深色间切换；旁边仅提供“跟随系统 / 浅色 / 深色”主题偏好。首次默认跟随系统，手动选择后保存。支持的浏览器双向播放从开关中心扩散的同一种圆形动画，保留日月、云海与帆船场景；不再提供动画等级或诊断菜单。减少动态效果时直接切换，缺少必要接口时内部安全降级。切换不重置输入、实验参数或答题进度。浏览器原生状态栏由浏览器控制，无法保证与页面逐帧同步。

## 这版可以学什么

- **7章、45个知识点**：信号基础、系统性质、LTI、傅里叶分析、采样、拉普拉斯变换与Z变换。
- **239道分步例题**：每个知识点5道，共225道；每章另有2道综合题，共14道。先读题独立尝试，再依次展开提示、推导和答案。
- **328道固定练习**：296道在有效作答条件下可客观判分（含19道新增绘图题），32道计算或推导题需要人工核对。支持按章节、知识点、难度与题型练习，收藏及错题重做。
- **31个参数化波形练习家族**：在信号变换、系统性质、卷积、傅里叶、采样实验中，先观察、预测并作答，再看解析和动画。同一家族可以换参数练习，不计作无限多道不同测评题。
- **六个预设实验室与五类自定义工作区**：比较时不变检验的两条路径，观察卷积重叠、谐波合成、混叠，以及极点零点；输入自己的CT/DT表达式并保存到信号库。
- 公式速查、搜索、章节结构、考试速记、复习标记及本地备份。

## 建议的学习路线

1. 在知识点页先读直觉和定义，自己写出核心公式及适用条件。
2. 对照5道例题逐步核对。需要看图时进入对应实验，先预测参数变化的结果。
3. 完成不同的客观题，再查看掌握状态；把不理解的步骤标为需要复习。
4. 错题重做正确后会移出错题本。准备更新掌握状态时，从知识点页开始“重新测评”，完成5道不同题并交卷。

## 掌握状态怎样计算

知识点至少完成**5道不同客观题**后才评估；章节至少完成**10道不同客观题，覆盖3个知识点**后才评估。未达到门槛时显示“样本不足”。达到门槛后：

| 客观正确率 | 状态 |
| --- | --- |
| 低于60% | 需要加强 |
| 60%至不足80% | 学习中 |
| 80%及以上 | 已掌握 |

同一轮中，每道题的首次有效作答计分。普通重做会保存练习记录、更新错题状态，但不会反复增加权重或改写本轮得分。重新测评在完成5道不同题并交卷后建立新轮次，保留测评历史摘要。计算、推导题的自评以及知识点页的快速自测不计入客观正确率。

旧版学习记录会迁移：已有作答次数与可用历史记录保留；原先手动标记的“已掌握”保留为复习信息，不直接当作新版客观掌握证据。详见 [Beta 测试说明](BETA.md)。

## 打开、主题与离线使用

直接访问上方网站链接。网站使用本地HTML、CSS、JavaScript及随目录附带的KaTeX，学习和计算不依赖在线API。

首次默认跟随系统深浅主题；顶部按钮可以切换深浅色，“项目说明”中的主题偏好可恢复跟随系统。选择会在当前浏览器保存。开启系统“减少动态效果”时省略主题过渡；不支持较新动画接口的浏览器使用轻量切换。

离线使用时，下载仓库的**完整ZIP**并解压，保留目录结构，用浏览器打开 `index.html`。在线网址不保证在断网后首次打开；完整本地文件夹可以离线运行。iPadOS“文件”的快速预览可能不执行脚本，应使用支持完整本地网页的浏览器或阅读工具，或访问静态站点网址。移动视口仿真不能替代iPad/Safari真机验证。

## 本地数据与内容来源

进度、收藏、错题、自定义信号、数字波形历史和测评记录保存在当前浏览器，不会自动同步到其他设备或上传。照片只在当前练习内暂存，离开后释放，不进入持久记录。清理网站数据、隐私模式、切换浏览器或网址来源可能影响记录，请定期在“项目说明”中导出学习记录，并单独导出自定义信号库。
